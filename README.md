# OnVizz

A web-based application that detects whether a given URL is **phishing** or **safe** using an ensemble of machine learning models. Users can simply input a link, and the system will return a risk assessment based on a combined prediction strategy.


## 🚀 Features

- 🔗 **URL Analysis**: Enter any URL to check for phishing threats.
- 🧠 **Ensemble Prediction**: Uses a majority voting system from 3 different models for higher accuracy.
- 📊 **Model Insights**: Results show how each model responded before ensemble decision.
- 🌐 **Web Interface**: Clean, user-friendly frontend for real-time phishing detection.
